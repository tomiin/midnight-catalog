See what's being built on Midnight, with the evidence shown.

Every project lists the public facts we could verify: does the repo exist, is it active, do the demo and contract check out. We show evidence, not verdicts. It is not an endorsement or a security audit.

How the checks work

An automated script reads public information only. A green check means the fact matched. It does not mean the project is good, safe, or endorsed.

RepositoryExists and is public, is not a fork, has a README, real commit history, recent activity, and an owner account that is not brand new.
Demo & videoThe links the builder provided actually load. Optional: skipped checks are shown in grey, not as failures.
ContractThe address has a valid format. On-chain lookup is not built yet, so we cannot confirm it exists on the network.

Automated checks cannot catch every scam, and a flag can be wrong. If your project is flagged unfairly, the builder can appeal by opening an issue. Always do your own research before connecting a wallet or sending funds.
