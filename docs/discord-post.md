Built a working prototype of the builder catalog idea @Eva: every Midnight project gets visible evidence checks (repo, history, demo, contract format, leaked-key scan), results are pinned to a commit hash and flip to "outdated" when the repo moves on. It shows evidence and flags, never verdicts or auto-bans, and it is not an audit. Open source, runs with plain Node. Try it: https://tomiin.github.io/midnight-catalog/  Code: https://github.com/tomiin/midnight-catalog  Review and feedback welcome, especially what you'd want checked first.
