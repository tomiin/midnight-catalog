Built a working prototype of the builder catalog idea @Eva: every Midnight project gets visible evidence checks (repo, history, demo, contract format, leaked-key scan), results are pinned to a commit hash and flip to "outdated" when the repo moves on. It shows evidence and flags, never verdicts or auto-bans, and it is not an audit. Open source, runs with plain Node. Review and feedback welcome, especially what you'd want checked first: https://github.com/tomiin/midnight-catalog (screenshots in the README)
